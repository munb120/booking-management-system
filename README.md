# Booking Management System

Ein einfaches Buchungsverwaltungssystem, entwickelt mit Node.js, Express.js und PostgreSQL.

## Funktionen

- Neue Buchungen erstellen
- Buchungen anzeigen
- Buchungen bearbeiten
- Buchungen löschen
- Buchungsstatus verwalten
- Buchungen in einer PostgreSQL-Datenbank speichern

## Technologien

- HTML & CSS
- JavaScript
- Node.js
- Express.js
- EJS
- PostgreSQL
- Git & GitHub

## Installation

**1. Repository klonen**

```bash
git clone https://github.com/DEIN-BENUTZERNAME/booking-management-system.git
```

**2. Abhängigkeiten installieren**

```bash
npm install
```

**3. Datenbank einrichten**

Erstelle eine PostgreSQL-Datenbank namens `booking_management` und führe die SQL-Befehle aus `database.sql` aus.

**4. `.env`-Datei erstellen**

```env
PORT=3000
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=booking_management
```

**5. Anwendung starten**

```bash
npm run dev
```

Öffne anschließend http://localhost:3000.
